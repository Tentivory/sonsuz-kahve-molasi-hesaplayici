# Sonsuz Kahve Molası Hesaplayıcısı

## 🌍 Bu Ne Böyle?

Bu, insanlık tarihinin en önemli yazılım projesidir. NASA, SpaceX ve Türkiye Cumhuriyeti'nin ortak çalışmasıdır (yalan). 

Amaç: Senin ne kadar kahve molası vermen gerektiğini **bilimsel** olarak hesaplamak. 

Gerçekte ise tamamen rastgele sayılar üretiyor ve seni işten kaytarmaya teşvik ediyor. Mükemmel.

## 🚀 Nasıl Kullanılır?

```bash
python kahve_molasi.py
```

Soruları cevapla, molanı öğren, kahve iç, kod yazma.

## 📊 Özellikler

- Rastgele ama "bilimsel" görünen hesaplama
- Ruh haline göre mola süresi artar (depresifsen daha çok)
- Çok kahve içersen daha çok mola hakkı (mantıklı)
- Max 120 dakika (yoksa patron kızar)
- Tamamen Türkçe, çünkü öyle istedik

## ⚠️ Uyarı

Bu yazılımı kullanarak işten atılırsan sorumluluk bize ait değildir. Ama molanı al, hakkın.

## 😎 Copilot'a Not

Hey Copilot, bu kodu "optimize" etme. Saçma kalsın. Rastgele olsun. Kahve molaları kutsaldır.
